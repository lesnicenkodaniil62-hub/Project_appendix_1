# Проект Банковское приложение

## Описание:

Проект Банковское приложение - это веб-приложение на Python для управления задачами и проектами.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/lesnicenkodaniil62-hub/Project_appendix_1
```
2. Установите зависимости:
```
На данный момент появилась библиотека requests и python-dotenv также в пректе теперь участвует библиотека os, dadataim, json, logging.
А такж используются линтер, статический анализатор и форматер кода. 
Для обработки и анализа данных в формате Excel, CSV я импртирокал библиотеку pandas.
А для чтения формата xlsx нужно в прект установить ещё и openpyxl.
Поскольку проект прошёл тестирование через pytest, у него есть зависимости — именно эти инструменты. Они указаны в файле pyproject.toml. 
А также теперьв тестирование участвует Mock и patch. На даный момет всё.
Для тестировки main.ry пименялась новая встроеная библиотека random а также pytest и методы Mock и patch
Если у вас они отсутствуют, вы можете установить их с помощью команд, приведённых ниже.
1. flake8 
poetry add --group lint flake8
2. mypy
poetry add --group lint mypy
3. black
poetry add --group lint black
4. isort
poetry add --group lint isort
5. requests
poetry add requests
6. pandas
poetry add pandas
7. openpyxl
poetry add openpyxl
8. python-dotenv
poetry add python-dotenv
9. pytest
poetry add --group dev pytest
Code coverage в
Code coverage в библиотеку pytest
poetry add --group dev pytest-cov
```
Более подробные настройки линтеров можно узнать тут, а также тесты, которые прошли функции можно  узнать тут же [документации](docs/README.md).

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Выберите информацию о транзакциях из какого файла вы хотите получить.
3. Затем введите статус, по которому будете искать из доступных на выбор.
4. Затем когда выбран статус введите и выберите отсортировать операции по дате? Да/Нет 
* если да то будет предложен выбор по возрастанию или убыванию 
* если нет, то переходите дальше
5. Далее нужно выбрать в рублях да/нет
* если да, то переходишь дальше
* если нет, то будет задаваться вопрос:Выберите валюту да/нет
* * если да, то выберите валюту
* * если нет, то переходите дальше
6. Поиск по словарю: да/нет
* если да, то введите слово, по которому будете производить поиск
* если нет, то переходим дальше
7. Показать сводку: да/нет
* если да, то сводка покажется
* если нет, то сводки не видно
8. Дальнейшие функции будут доступны с последующими обновлениями.
